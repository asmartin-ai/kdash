- Created a fresh branch `resync-from-upstream` from `upstream/main` (v1.3.1, SHA `6deb1ed`).

## Re-enablement checklist

If you want Antigravity quota back:
1. Uncomment the antigravity lines in `src/tokdash/sources/quota/__init__.py`
   (import + dispatch + `_network_key_for_provider`).
2. Re-add `"antigravity_api"` to `QUOTA_KEYS` in `src/tokdash/sources/quota/config.py`.
3. Uncomment the antigravity entries in `src/tokdash/static/index.html`
   (visibility dropdown, `quotaProviderLabel`, `quotaConsentMeta`,
   `quotaSeriesLabel`, `renderAntigravityPools` dispatch, chart series collapse).
4. Revert the consent-dict assertions in `tests/test_api_quota.py`,
   `tests/test_quota_config.py`, `tests/test_cli_serve.py` to include
   `"antigravity_api": False`.

The `antigravity.py` collector module and its standalone tests are untouched and
still work as-is — they just won't be dispatched from `collect_network_snapshots()`
until step 1 above.

If you want the dropped suggest features back:
1. Re-add `ZENMUX_FREE` entries.
2. Re-add `has_freebuff: bool = True` parameter.
3. Re-add `supergrok_end` / `supergrok_proxy` parameters and their SG trial logic.
4. Re-add `anthropic/claude-fable-5` to `AVOID_ON_STARTER`.

The `tests/test_suggest.py` file will need to be restored from the
`pre-resync-snapshot` tag if you want the old tests back.
